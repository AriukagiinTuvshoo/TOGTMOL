# Тогтмол v4 — Cute Study World

**Өөрийн хэмнэлээр, нэг жижиг алхам.**

Тоги хамтрагчтай суралцах өрөө. v3-ийн хичээл, календарь, хугацаа, тэмдэглэл, статистик, нөөц, Supabase холболтыг үргэлжлүүлэн хөгжүүлсэн Next.js төсөл.

![Cozy Cat өрөөний зураг](docs/previews/cozy.svg)

## Ажиллуулах

Node.js **24** ашиглана.

```bash
git clone https://github.com/AriukagiinTuvshoo/TOGTMOL.git
cd TOGTMOL
npm ci
npm run dev
```

Браузераар `http://localhost:3000` нээнэ. **Хичээлүүд → Хичээл нэмэх → Миний өрөө → Start study**.

Supabase болон AI түлхүүргүйгээр үндсэн апп ажиллана. Энэ нь Next.js төсөл тул HTML файл шиг давхар дарж нээхгүй. Өмнөх дан HTML хувилбар `legacy/togtmol-v2.html` дотор хадгалагдсан.

```bash
npm run build
npm start
```

## v4-д нэмэгдсэн

- **Суралцах өрөө:** Тоги, хичээл сонголт, цаг хэмжигч, өнөөдрийн зорилго, төлөвлөгөө, сүүлийн тэмдэглэл.
- **Таван загвар:** Cozy Cat, Minimal Focus, Night Study, Forest Study, Sakura. Өнгө, хэлбэр, өрөө, хамтрагч, уур амьсгал хамт солигдоно; сонголт хадгалагдана.
- **Тоги:** өөрсдөө зурсан зургаан төрх — үнэг, муур, баавгай, туулай, оцон шувуу, нохой. Суралцах, түр зогсох, амрах, дуусгах, эргэн ирэхэд өөрчлөгдөнө.
- **Өрөө тохируулах:** арван орчин, таван гэрэл/цаг агаар, ширээний долоон зүйл, хувцас, илэрхийлэл, чимэглэл.
- **Зөөлөн ахиц:** хэмжсэн хугацаанаас XP; эхний 30 минут 1 XP/минут, дараагийн 60 минут 0.5 XP/минут, өдөрт дээд тал нь 60 XP. Гараар тэмдэглэсэн өдөр болон зассан хугацаанаас XP авахгүй. Бүх өрөө, хамтрагч анхнаасаа нээлттэй.
- **Хөгжим:** өөрсдийн үүсгэсэн зургаан ая/чимээ, дууны түвшин, хаах, өмнөх/дараах, жижиг тоглуулагч. Хуудас солиход тасрахгүй; өөрөө асахгүй.
- **YouTube:** бичлэг/жагсаалтын холбоос хадгалж албан ёсны тоглуулагчаар үзнэ. Тоглуулагчийг багасгах, өөр tab руу орох, харагдахгүй болгоход түр зогсоно. Зар сурталчилгаа, хязгаарлалтыг өөрчлөхгүй.
- **Төвлөрөх горим:** өрөө, хичээл, хугацаа, ахиц, хөгжим ба үндсэн удирдлага. Escape эсвэл гарах товчоор буцна; хугацаа үргэлжилнэ.
- **Зорилго → төлөвлөгөө → хичээл:** бичсэн зорилгоос засаж болох хуваарь санал болгоно. Хадгалахаас өмнө бүх алхмыг харна. Зорилгын ахиц нь холбогдсон timer-ийн бодит хугацаа; төлөвлөгөөг чагтлах нь минут нэмэхгүй.
- **Тоги туслах:** бодит цаг, зорилго, тэмдэглэлээс local хариулт өгнө. Онлайн AI-г тусдаа зөвшөөрлөөр ашиглах серверийн холболт бэлэн; түлхүүргүй үед local горим ажиллана.
- **Гар утас:** Нүүр / Календарь / Timer / AI · Тоги / Бусад. Хөдөлгөөн багасгах системийн тохиргоог дагана.

## Хадгалсан v3 боломжууд

Stopwatch ба Pomodoro; pause/resume; сэргээхэд эхэлсэн мөчөө хадгалах; тэмдэглэлээ түр хадгалах; Finish → Save result; амралтыг суралцсан цагт тооцохгүй. 30/90/365 өдрийн календарь, сарын харагдац, хичээлийн шүүлт, 7/30/90/365/бүх хугацааны статистик, өдрийн/долоо хоногийн/сарын зорилго, амжилтууд хэвээр.

Хичээл, хичээлийн түүх, төлөвлөгөөг устгаж/сэргээж болно. JSON экспорт, нэгтгэх, зөрчил шийдэх, эх өгөгдлийн нөөц, Supabase бүртгэл тусгаарлалт болон offline өөрчлөлтийн sync хадгалагдсан.

## Өгөгдлөө шилжүүлэх

Ижил браузер/домэйн дээр v3-ийн өгөгдлийг нээхдээ **эх хадгалалтыг нөөцөлсний дараа** v4 рүү шилжүүлнэ. IndexedDB-ийн `togtmol-v3` нэрийг зориуд хэвээр үлдээсэн. Нөөц амжилтгүй бол шилжүүлж бичихгүй.

Өөр браузер/домэйн/порт ашиглах бол хуучин хувилбараас JSON экспортлоод **Тохиргоо → JSON файл нэгтгэх** хэсэгт оруулна. v2, v3, v4 файлыг танина. Танигдаагүй мөрийг эхээр нь `quarantine` дотор хадгална. v4 экспортын `version` нь **4**; хуучин v3 апп v4 файлыг уншихгүй.

[Шилжилт ба сэргээх](docs/MIGRATION.md) · [Архитектур](docs/ARCHITECTURE.md).

## Бүртгэл, онлайн AI, байршуулах

[Байршуулах заавар](docs/DEPLOYMENT.md)-ын дагуу Supabase-ийн хоёр migration-ийг дарааллаар нь хэрэглэнэ. Одоо байгаа v3 санд зөвхөн шинэ v4 migration хэрэгтэй.

`.env.example` нь шаардлагатай хувьсагчдын нэрийг агуулна. Онлайн Тогид серверийн `OPENAI_API_KEY`, `OPENAI_MODEL`, зөвшөөрөгдсөн Supabase хэрэглэгчдийн `TOGI_AI_ALLOWED_USER_IDS` хэрэгтэй. Хэрэглэгч тус бүрт өдөрт 20 асуултын хадгалагддаг хязгаар үйлчилнэ. Түлхүүрийг браузерт эсвэл GitHub-д оруулахгүй.

GitHub нь эх кодыг хадгална. Аппыг интернетэд ажиллуулахад Vercel эсвэл Node.js сервер хэрэгтэй; GitHub Pages-д зориулсан дан статик хувилбар биш.

## Шалгалт

```bash
npm run check
npm run format:check
npm run build
```

`check` нь TypeScript, ESLint, бүх тест, production build-ийг ажиллуулна. [Шалгалтын тайлан](docs/VERIFICATION.md) нь баталгаажуулсан зүйл болон бодит үйлчилгээ/төхөөрөмж дээр үлдсэн шалгалтыг ялгаж тайлбарласан.

Өрөөний баримтын зургийг дахин үүсгэх: `node scripts/render-room-previews.mjs`.

## Одоогийн хязгаар

- Онлайн AI, hosted Supabase болон Google нэвтрэлтийг бодит түлхүүртэй орчинд холбож шалгаагүй.
- YouTube-д интернет, тухайн бичлэгийн embed зөвшөөрөл хэрэгтэй. Бодит playback-ийг энэ орчны браузерт баталгаажуулаагүй.
- PWA-г production build, HTTPS дээр анх бүрэн нээсний дараа үндсэн суралцах боломжууд offline ажиллана. Бодит iOS/Android install болон responsive харагдацын эцсийн шалгалт үлдсэн.
- Сануулах цаг апп нээлттэй үед ажиллана. Timer төхөөрөмж бүрт тусдаа.
- Браузерын бүх өгөгдлийг цэвэрлэхэд локал нөөц ч арилна; JSON экспорт төхөөрөмж хооронд түүхээ зөөхөд хэрэгтэй.
