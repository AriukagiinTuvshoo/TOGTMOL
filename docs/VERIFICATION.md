# Тогтмол v7 — шалгалтын тайлан

Огноо: 2026-11-12. Орчин: Linux (cloud), Node.js 26.13.0, Next.js 16.3.8, TypeScript 6.0.3, React 19.3.0, апп 7.0.0. Өмнөх тайлан (v5, 2026-09-22) нь энэ файлыг орлов; түүхэн Phase-ийн шийдвэрийг [v7 суурь](BASELINE-7.md)-аас харна.

Доорх нь **энэ орчинд бодитоор ажиллуулсан** шалгалт. Бодит Supabase төсөл, хоёр дахь хэрэглэгч/төхөөрөмж, Lighthouse/Core Web Vitals болон screen reader-ийг ажиллуулж чадаагүй зүйлсийг тусад нь (§4) жагсаав.

## 2. Функциональ хамрах хүрээ (тестээр)

- **Хадгалалт ба шилжилт:** v2/v3/v4/v5 → schema 6, ID/түүх/таймер, танигдаагүй талбар, буруу мөрийг quarantine-д, экспорт → импорт, сэргээх (хаалттай getter, эвдэрсэн JSON, revision, quota, зэрэг бичилт), CAS-тай буцаах.
- **Синк:** хоёр хэрэглэгчийн тусгаарлалт, гурван хувилбарын merge, tombstone, зөрчлийн хоёр хувилбар, knowledge round trip, atomic push, хуучин схемийн upload-аас татгалзах, quota, reset epoch. **Хоёр бодит төхөөрөмж/хэрэглэгчээр туршаагүй** (§4).
- **Мэдлэг:** тэмдэглэл, хайлт (36 бичлэг, 100,000 картын индекс), хогийн сав, хуучирсан хувилбар дээр давхар засвар хорих.
- **Давтлага:** SM-2 интервал/ease/алдааны дахин эхлэл, нэг өдрийн доторх давтлагын дүрэм, давхар review хорих, өдрийн шинэ картын хязгаар (анхдагч 20), сессийн хэмжээ (200, тохируулгатай), багц шүүлт, цагийн тоолуур.
- **FSRS:** муруй `R(S,S)=0.9`, интервал `I(0.9,S)=S`, үнэлгээний буулгалт, `S0/D0`, амжилт/алдааны тогтвортой байдал, түүхээс нэг параметрийн калибровк (40+ ажиглалт, 0.005 gain), `migrate()` round-trip.
- **Импорт/экспорт:** Anki meta толгой, RFC 4180 ишлэл, HTML цэвэрлэлт, давхардал алгасах, TSV/CSV round-trip, 500 картын импорт нэг өдрийн хязгаарт.
- **PDF:** Flate болон шахалтгүй stream, `Tj/TJ`, escape, `ToUnicode` CMap (кирилл), тэмдэгтийн хязгаар, текстгүй/PDF биш файлын алдаа.
- **Сорил:** сонгох/үнэн-худал/богино хариулт, асуултын snapshot, давхар attempt хорих, буруу хариултаас карт үүсгэх.
- **PWA ба төхөөрөмж:** asset нөөцлөлт, auth/API/гаднын хүсэлтийг cache-д оруулахгүй байх, wake lock, сануулгын нэг удаагийн claim. Бодит төхөөрөмж дээр суулгаагүй (§4).
- **Хүртээмж (код):** mobile "Бусад" sheet нь `dialog`/`aria-modal`/Escape/focus trap/return focus; давтлагын цонхны барьцаа `aria-live`; бүх товч төрөлтэй.

- Консолоос илэрсэн `info` icon-ы SVG path алдаа засагдсан; `/manifest.webmanifest` 403 нь preview host-ийн нэвтрэлтийн онцлог.

### 3.1 Contrast (WCAG 2.1 AA) хэмжилт

Lighthouse энэ VM дээр ажиллахгүй тул contrast-ыг DOM дээр шууд хэмжсэн: текст зангилаа бүрийн өнгө, түүний доорх бодит дэвсгэрийг (transparent/`color-mix` давхаргыг холино) тооцож, 4.5:1 (том/тод текстэд 3:1) шаардлагатай харьцуулсан.

- **Өмнө:** 11 route-оос 13 failure. Хамгийн муу нь `--muted` `#776d61` фоны `#e5eadd` дээр **4.14**, `--moss` `#667b60` мөн дээр **3.75**, `.skip-link` цайвар текст **4.49**, neon сэдвийн идэвхтэй tab (navy 86% on `#8d5cff`) **3.86**.
- **Засагдсан:** `lib/world/room-themes.ts`-ийн 10 сэдвийн `muted` болон `accent` токеныг зөвхөн шаардлага хангах хэмжээгээр бараантуулав (жишээ нь cozy `muted` `#6f655a` = 4.65, `accent` `#5a6c54` = 4.62); `app/globals.css`-ийн `.skip-link` төвийг сахисан хар/цагаан болгов; `app/neon.css`-д идэвхтэй мэдлэгийн tab-д гүн violet + цагаан (6.2:1) нэмэв.
- **Дараа:** 11 route (нүүр, timer, calendar, subjects, statistics, goals, settings, knowledge, world, assistant, trash) болон dark theme дээр **0 failure**.
- **Хамгаалалт:** `tests/theme-contrast.test.ts` (10 тест) нь 10 өрөөний гэрэл палитр бүрийн `muted`/`accent`-ыг тухайн сэдвийн бүх дэвсгэр дээр 4.5:1-ээс доош буухыг хориглоно.

## 5. Дүгнэлт

`main` дээр локал шалгалт бүрэн ногоон (typecheck, lint, format, 305 тест, build). Браузер дээр үндсэн урсгалууд (импорт, давтлага, багц шүүлт, тоолуур) ажиллаж байгааг нүдээр баталсан, contrast нь 11 route дээр 0 failure болтол засагдаж, тестээр хамгаалагдсан. **Production орчин, хоёр бодит төхөөрөмжийн синк, Lighthouse-ийн Core Web Vitals хийгдээгүй** — тэдгээрийг тэнцсэн гэж тайлагнахгүй.
