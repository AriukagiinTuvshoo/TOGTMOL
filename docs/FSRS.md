# FSRS — сонголтоор хэрэглэх давтлагын алгоритм (Phase 3)

Огноо: 2026-11-12. SM-2 нь анхдагч хэвээр; FSRS-ийг хэрэглэгч **Тохиргоо → Давтлагын алгоритм** хэсгээс сонгоно. Хуучин карт, түүх, синк, экспорт бүгд хэвээр ажиллана.

## 1. Яагаад SM-2-ыг орхихгүй вэ?

SM-2 нь 1987 оны алгоритм бөгөөд хэрэглэгчийн санах чадварыг загварчлахгүй, зөвхөн `ease` коэффициентээр интервалыг үржүүлдэг. FSRS нь DSR (Difficulty, Stability, Retrievability) загвараар «мартах муруй»-г тооцдог тул ижил ачаалалд цөөн давтлага шаарддаг. Гэхдээ:

- одоо байгаа 100,000 картын индекс, queue, түүх, синк бүгд SM-2-ийн `repetitions/interval/ease/dueOn` талбарт тулгуурладаг;
- FSRS-ийг албадан сольсноор хуучин түүх утгагүй болж, хэрэглэгчийн хуваарь гэнэт өөрчлөгдөнө.

Тиймээс FSRS нь **сонголт** бөгөөд ижил `ReviewSchedule` бүтцийг буцаадаг. Нэмэлт талбарууд (`algorithm`, `stability`, `difficulty`, `lastReview`) зөвхөн FSRS-ээр хуваарьлагдсан картад байна.

## 2. Хэрэгжүүлэлт

`lib/knowledge/fsrs.ts` — FSRS-4.5, 17 параметр, нийтлэг анхдагч жин:

```text
0.4872, 1.4003, 3.7145, 13.8206, 5.1618, 1.2298, 0.8975, 0.031, 1.6474,
0.1367, 1.0461, 2.1072, 0.0793, 0.3246, 1.587, 0.2272, 2.8755
```

- Мартах муруй: `R(t,S) = (1 + 19/81 · t/S)^(-0.5)`, `R(S,S) = 0.9`.
- Интервал: `I(r,S) = S/(19/81) · (r^(1/-0.5) − 1)`, `r = 0.9` үед `I = S`.
- Анхны тогтвортой байдал `S0(G) = w[G−1]`, анхны хүндрэл `D0(G) = w4 − e^(w5·(G−1)) + 1`, `D ∈ [1,10]`.
- Амжилттай давтлагад `S' = S·(e^w8·(11−D)·S^(−w9)·(e^(w10·(1−R))−1)·w15(хэрэв G=2)·w16(хэрэв G=4) + 1)`, амжилтгүйд `S' = w11·D^(−w12)·((S+1)^w13 − 1)·e^(w14·(1−R))`.
- Хүндрэл: `ΔD = −w6·(G−3)`, `D' = D + ΔD·(10−D)/9`, дараа нь `D0(3)` руу буцаах дундажлал (`w7`).

**Үнэлгээний буулгалт.** Апп 0–5 үнэлгээтэй (SM-2). FSRS дөрвөн үнэлгээтэй тул: `0–2 → Again`, `3 → Hard`, `4 → Good`, `5 → Easy`. Энэ нь «4-өөс доош үнэлсэн карт энэ давтлага дотор дахин гарна» гэсэн одоогийн зан төлөвийг хадгална.

**Хязгаарууд.** Амжилттай давтлагад тогтвортой байдал буурахгүй (`S' ≥ S`), алдааны дараа `0.01 ≤ S' ≤ S`, интервал `1…36500` хоног, коэффициент `0.5…2`. FSRS-4.5 нь нэг өдрийн доторх давтлагыг тусгайлан загварчлахгүй тул SM-2-ийн «нэг суралцах өдрийн дотор олон өдрийн шат руу үсрэхгүй» дүрэм хэвээр (өдрийн эхний давтлагын `before`-ыг ашиглана).

## 3. Түүхээс сурах

`lib/knowledge/calibrate.ts` — бүрэн FSRS сургалт (17+ жин, мянган давтлага, градиент) биш, **нэг параметрийн калибровк**:

1. Нэг картын дараалсан хоёр давтлагаас нэг ажиглалт гаргана: `(өнгөрсөн хоног, амжилт/алдаа, өмнөх интервал)`.
2. SM-2-ийн интервалыг 90% хадгалалтын тогтвортой байдлын ойролцоо утга гэж үзнэ.
3. `0.5…2.0` хооронд 0.05 алхмаар тогтвортой байдлын коэффициент хайж, ажиглагдсан үр дүнг хамгийн сайн тайлбарлахыг сонгоно (log-loss).
4. 40-өөс доош ажиглалттай бол юу ч өөрчлөхгүй; сайжруулалт нэг ажиглалтад 0.005-аас бага бол мөн анхдагчаа үлдээнэ.

Үр дүн нь `settings.extras.fsrsScale`-д хадгалагдаж, зөвхөн FSRS-ийн интервалыг үржүүлнэ. Түүх, карт, SM-2-ийн `ease` хөндөгдөхгүй. Хэрэглэгч «Түүхээс тохируулах» дарахад л ажиллана — автоматаар биш.

## 4. Шалгалт

`tests/fsrs.test.ts` — 19 тест:

- муруй `R(S,S)=0.9`, `I(0.9,S)=S`, цаг хугацааны бууралт, 0–1 хязгаар;
- үнэлгээний буулгалт, анхны `S0/D0`, хүндрэлийн өсөлт/бууралт, амжилт/алдааны тогтвортой байдал;
- `elapsedDays` (lastReview ба dueOn-оос), детерминизм, буруу үнэлгээний татгалзал;
- калибровк: өдрийн доторх давтлагыг алгасах, 40-өөс доош түүхэд өөрчлөхгүй, таамаглалтай нийцсэн түүхэд анхдагч хэвээр, илүү мартах → коэффициент буурах, илүү санах → өсөх;
- интеграци: SM-2 анхдагч хэвээр, FSRS сонгоход карт ба түүхэд төлөв хадгалагдах, дараагийн давтлагад интервал өсөх, коэффициент нөлөөлөх, `migrate()` round-trip.

## 5. Хязгаар ба дараагийн алхам

- FSRS-4.5-ийн 17 жингийн зөвхөн нэг хослолыг (тогтвортой байдлын коэффициент) түүхээс сурдаг. Бүрэн жин сургах нь сервер талын ажил (мянган давтлага, оптимизатор) — Phase 3-ийн дараагийн боломж.
- FSRS-5/6-ийн нэмэлт (нэг өдрийн доторх тогтвортой байдал, суралцах алхам) ороогүй.
- Бодит хэрэглэгчийн түүхээр коэффициент буруу тийшээ хазайх эрсдэлийг 40 ажиглалт + 0.005 gain босгоор хязгаарласан; илүү урт түүхээр дахин шалгах нь зүйтэй.
- Anki импорт/экспорт, PDF/текстээс карт үүсгэх нь Phase 3-ийн үлдсэн зүйл.
