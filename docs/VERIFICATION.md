# Тогтмол v5 — шалгалтын тайлан

Огноо: 2026-09-22. Орчин: Linux, Node.js 24.19.0, Next.js 16.3.5, TypeScript 6.0.3. Суурь: v4.1 (`274ac692fcdaffaa8b715c4f79fedf48f02c4b56`). Доорх нь эх кодын локал шалгалт; бодит үйлчилгээ, төхөөрөмжийн шалгалтыг тусад нь ялгасан.

## Автомат шалгалт

| Шалгалт                      | Үр дүн                                                                                             |
| ---------------------------- | -------------------------------------------------------------------------------------------------- |
| Хамаарлууд                   | Хувилбаруудыг солиогүй; аппын хувилбар 5.0.0 болсон                                                |
| TypeScript                   | Алдаагүй                                                                                           |
| ESLint                       | Алдаа, анхааруулгагүй                                                                              |
| Vitest                       | **146 / 146** тест, **17 / 17** файл                                                               |
| `npm run check`              | TypeScript → ESLint → тест → production build бүгд тэнцсэн                                         |
| `npm run build`              | Тусад нь дахин ажиллуулахад тэнцсэн                                                                |
| `npm run format:check`       | Код болон баримтын формат тэнцсэн                                                                  |
| Production route             | Нүүр, 404, manifest, `/api/bondook`, `/api/bondook/cards`, `/api/bondook/plan`, хуучин `/api/togi` |
| Offline manifest             | **25** өөрчлөгдөхгүй JS/CSS asset                                                                  |
| 100,000 карт + 10,000 хичээл | Индекс үүсгэх, хайлт, 40 үр дүнгийн хязгаар зөв; 5 секундийн дээд хязгаарт тэнцсэн                 |
| PostgreSQL                   | Гурван migration, арван public хүснэгт, RLS/CAS/rollback болон үүлэн устгалын шалгалт тэнцсэн      |

Эхний build өмнөх Turbopack кэшийн тасарсан `.sst` файл дээр зогссон. Үүсмэл build кэшийг тусгаарлаж, `npm run check`-ийг цэвэр кэштэй дахин ажиллуулахад бүх шат тэнцсэн. Аппын эх код, хэрэглэгчийн хадгалалтыг энэ засварт өөрчлөөгүй.

Гүйцэтгэлийн тест нь Node дахь индекс/хайлтын хэмжилт. Браузерын бүтэн дүрслэл, 100,000 зурагтай картын IndexedDB бичилт, импорт, сүлжээ болон төхөөрөмжийн багтаамжийн баталгаа биш. Мэдлэгийн дэлгэц болон багцын картууд хязгаартай хэсгээр нэмэгдэж харагдана.

## Шалгасан урсгалууд

- **Хуучин өгөгдөл:** v2/v3/v4 → v5 шилжилт, ID/түүх/таймер, танигдаагүй нэмэлт талбар, буруу мөрийг тусгаарлан хадгалах, давхар хичээлийн холбоос, экспорт → импорт. Шилжүүлэлт эх хадгалалтаа нөөцөлсний дараа хийгдэнэ.
- **Сэргээх:** хаалттай `localStorage` getter, IndexedDB дахин нээх, эвдэрсэн JSON/revision-ийн эх файлыг хадгалах, quota болон зэрэг бичилтийн алдаа, explicit restore, зөв бүртгэлийн namespace. IndexedDB-ийн мэдлэгийн мөрүүд тусдаа хадгалагдаж, өөрчлөгдөөгүй зургуудыг тохиргоо солих бүрд дахин бичихгүйг шалгасан.
- **Нөөц ба нууцлал:** өдрийн эхний өөрчлөлтийн нөөц, бүрэн экспорт, бүртгэл солигдох үеийн импортын хамгаалалт, локал цэвэрлэгээний нөөц/CAS, AI унтраахад ярилцлага үлдэх, сануулгыг зэрэг цонхонд давхар гаргахгүй байх.
- **Миний мэдлэг:** тэмдэглэл үүсгэх, текст/хичээл/шошго/огноогоор хайх, `Ctrl/⌘ K`, холбоосын шалгалт, хогийн сав, буцаах, хуучирсан хувилбар дээр засвар давхардуулахгүй байх.
- **Карт:** багц/картын холбоос, SM-2 үнэлгээ, дахин санах, суралцах өдрийн хязгаар, нэг өдөр давтахад хугацааг олон өдрөөр давхар ахиулахгүй байх, давхар review бичихгүй байх, хааж дахин нээхэд давтлагын түүх хадгалагдах.
- **Сорил:** сонгох, үнэн/худал, богино хариултын үнэлгээ, үр дүнд асуултын snapshot хадгалах, давхар attempt үүсгэхгүй байх, буруу хариултаас карт үүсгэх.
- **Бондоок ба санал:** нэр/төрх/арван загвар, бодит түүхэд тулгуурласан local хариулт, ярилцлагын хадгалалт, карт болон төлөвлөгөөний саналыг шалгах, серверийн бүтэцтэй хариуг баталгаажуулах. Хүсэлт нь хэрэглэгчийн сонгосон өгөгдөл ба зөвшөөрлийн хүрээнд хязгаарлагдана.
- **Онлайн API:** нэвтрэлт, allowlist, өдөрт 20 хүсэлтийн atomic quota, хүсэлтийн хэмжээ, зураг илгээх тусдаа зөвшөөрөл, буруу хариунаас татгалзах, raw upstream алдаа/түлхүүр задруулахгүй байх. Хиймэл түлхүүр, орлуулсан provider ашигласан; төлбөртэй хүсэлт илгээгээгүй.
- **Хугацаа ба ахиц:** эхэлсэн мөч, pause/resume, сэргээх, Pomodoro, review/save, экспортын snapshot, шөнө дамнасан хуваарилалт, зорилго/үе шатны холбоос, бодит хэмжилтээр ахиц ба XP тооцох. Амралтын өдөр нэмэхэд хийсвэр XP/минут үүсэхгүй.
- **Хөгжим:** есөн ая/чимээний бодит тоон sample, эхлүүлэх/түр зогсоох/үргэлжлүүлэх/цэвэрлэх, автоматаар асахгүй байх, хуудас солих үеийн удирдлага. YouTube-ийн 12 удаагийн mount/unmount, хожуу callback, салсан adapter болон модулийн алдааны тусгаарлалт.
- **Төхөөрөмжийн API:** wake lock авах/чөлөөлөх/дахин авах, дэмжигдэхгүй болон зөвшөөрөгдөөгүй нөхцөл. Эдгээр API-г тестэд орлуулсан.
- **Синк ба SQL:** хоёр хэрэглэгчийн тусгаарлалт, гурван хувилбарын merge, tombstone, зөрчлийн хоёр хувилбарыг хадгалах, knowledge round trip, atomic push, хуучин схемийн upload-аас татгалзах, quota хамгаалалт. Үүлэн устгалд owner + revision шаардлагатай; хуучин төхөөрөмжийн мэдээлэл буцаж ороход reset epoch болон тусдаа зөвшөөрөл шаардлагатай. Синк унтраах болон бүртгэл солих үеийн хожуу хүсэлтийг шалгасан.
- **PWA:** эх кодын asset нөөцлөлт, auth/Supabase/API/гаднын хүсэлтийг cache-д оруулахгүй байх, хуучин cache цэвэрлэх, хуучин цонхыг хүчээр шинэчлэхгүй байх.

React урсгалууд **jsdom** дээр ажилласан. SQL шалгалтууд **PGlite PostgreSQL engine** дээр migration-уудыг бодитоор ажиллуулсан. Хөгжмийн тоон өгөгдлийг шалгасан боловч чанга яригчаар сонсож баталгаажуулаагүй. Орлуулсан YouTube API тест жинхэнэ сүлжээ/playback-ийн баталгаа биш.

## Зургийн шалгалт

Бондоокийн зургаан төрх болон шинэ таван өрөөний SVG-г PNG болгон нүдээр шалгасан. Уулын байшингийн цонх, ханын зургийг засварын дараа дахин шалгасан. `docs/previews/` дахь зургууд аппын өөрийн SVG asset-аас үүссэн; браузерын бүтэн дэлгэцийн зураг биш.

## Бодит орчинд үлдсэн шалгалт

Браузерын орчин localhost хандалтад `ERR_BLOCKED_BY_CLIENT` өгсөн. Тиймээс 320/375/390/430/768/1024/1440 өргөний бодит дүрслэл, браузерын console, жинхэнэ YouTube тоглолт, iOS/Android install болон төхөөрөмж дээрх offline ажиллагааг тэнцсэн гэж тайлагнаагүй. CSS, keyboard/диалог, accessible label, хөдөлгөөн багасгах тохиргоо болон тестээр шалгах боломжтой урсгалуудыг хийсэн.

Бодит Supabase төсөл, AI түлхүүр, Google provider, live URL тохируулаагүй. Байршуулахдаа v5 SQL migration хэрэглэж, email confirmation, Google callback, password recovery, хоёр бодит төхөөрөмжийн синк/үүлэн устгал, онлайн AI болон зураг уншуулах урсгалыг шалгана. [Байршуулах заавар](DEPLOYMENT.md).

GitHub-ийн тусдаа шалгалтыг [Actions](https://github.com/AriukagiinTuvshoo/TOGTMOL/actions) хэсгээс харна. Энэ тайлан CI үр дүнг урьдчилан тэнцсэн гэж үзээгүй.
