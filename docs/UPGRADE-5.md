# v5-ийн инженерийн тэмдэглэл

Өмнөх баталгаажсан суурь: v4.1, `274ac692fcdaffaa8b715c4f79fedf48f02c4b56`. v5 кодын болон өгөгдлийн өөрчлөлтүүдийг ижил төсөлд нэмсэн; шинэ төсөл болгон хуучин түүхийг орхиогүй.

Байршуулсан хувилбарын URL, console/алдааны бүртгэл өгөөгүй. Иймээс эдгээрийг хэрэглэгчийн харсан үйлдвэрлэлийн алдааны ганц шалтгаан байсан гэж дүгнээгүй. Кодод байсан алдааны замуудыг засаж, давтагдах нөхцөлийг тестээр шалгасан.

## Нэмсэн бодит боломжууд

Тэмдэглэл/зураг/холбоосын сан, хайлт ба шүүлтүүр, карт/багц/SM-2/давтлагын түүх, сорил/үр дүн/алдаанаас карт, Бондоокийн байнгын нэр/дүр/ярилцлага, онлайн карт ба төлөвлөгөөний засаж хянах урсгал, шинэ таван өрөө, шинэ хоёр ая, нөөц/нууцлалын төв, үе шаттай сэргээх, зөвшөөрөлтэй үүлэн цэвэрлэгээ, дэлгэц сэрүүн байлгах, суралцах өдрийн эхлэл, амралтын өдөр, сануулгын сонголтууд, мэдлэгийн статистик ба амжилтууд.

## Хэрэглэгчийн урсгалаар шалгах

1. Хуучин JSON импортлоод ID, хугацаа, тэмдэглэл, зорилго, идэвхтэй таймераа тулгана.
2. Хичээл эхлүүлж түр зогсоох/үргэлжлүүлэх; хөгжим нээгээд өөр дэлгэц рүү орно; хичээлээ хадгална.
3. Өнөөдрийн зурагтай тэмдэглэл нэмээд шошго/текстээр хайна. `Ctrl/⌘ K`-аар шууд нээнэ.
4. Багцад карт нэмэж, хариултаа өөрөө санаж үнэлнэ; хааж дахин нээгээд түүх ба дараагийн өдрийг шалгана.
5. Гурван төрлийн асуулттай сорил өгч, буруу хариултуудаа багц болгоно.
6. Карт/төлөвлөгөөний санал гаргаад хадгалахаас өмнө засна. Онлайн горимгүй үед гаднын хүсэлт гарахгүйг шалгана.
7. Мэдлэгээ хогийн саванд шилжүүлээд буцаана; JSON нөөцөө өөр тусгаарласан браузерт импортлоно.
8. Үүлэн тохиргоотой туршилтын орчинд хоёр хэрэглэгч/хоёр төхөөрөмжийн зөрчил ба устгалын хамгаалалтыг шалгана.

Автомат тест болон бодит үйлчилгээ/төхөөрөмжийн ялгааг [VERIFICATION.md](VERIFICATION.md)-д, серверийн шинэчлэлтийг [DEPLOYMENT.md](DEPLOYMENT.md)-д тайлбарласан.
