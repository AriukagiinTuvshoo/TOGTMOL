# Импорт, экспорт ба материалаас карт бэлдэх

Огноо: 2026-11-12. Бүх боловсруулалт төхөөрөмж дээр; файл сервер рүү явахгүй (онлайн Бондоокыг санаатайгаар асаахаас бусад тохиолдолд).

## 1. Anki / CSV солилцоо

**Anki → энэ апп.** Anki дээр `Файл → Экспорт → Тэмдэглэл` (Notes in Plain Text) сонгоод `.txt`, `.csv` эсвэл `.tsv` файлыг гаргана. Дараа нь Тохиргоо → «Импорт ба экспорт» хэсэгт файлаа сонгох эсвэл агуулгыг нь буулгана.

Модуль: [`lib/knowledge/anki.ts`](../lib/knowledge/anki.ts).

- Тусгаарлагчийг автоматаар танина (tab / `,` / `;`), Anki-ийн `#separator`, `#html`, `#tags column`, `#deck column` толгой мөрүүдийг уншина.
- RFC 4180 ишлэл: талбар доторх таслал, шинэ мөр, давхар ишлэл зөв уншигдана.
- `#html:true` үед Anki-ийн HTML-ийг цэвэрлэнэ: `<br>`/`<div>` → шинэ мөр, `<b>` зэрэг таг хасагдана, `&nbsp;`/`&amp;`/`&lt;` тайлагдана, `[sound:…]` хасна.
- Толгой мөр (`front,back,tags,deck` гэх мэт) байвал талбарын байрлалыг түүнээс тодорхойлно; нэмэлт талбарууд хариултад шинэ мөрөөр нэгдэнэ.
- Хоосон асуулт/хариулттай мөр, 2000-аас хэтэрсэн карт алгасагдана; асуулт 4,000, хариулт 10,000 тэмдэгтээр таслагдана.
- Багц үүсгэх эсвэл одоогийн багцад нэмэх; сонгосон багцад ижил асуулт (жижиг үсэг, NFKC, зай нормчилсон) байвал **алгасна** — давхар импорт багцыг хоёр дахин нэмэхгүй.
- Файл дахь багцын нэрээр тусад нь хуваах сонголт бий (Anki-ийн `#deck column`).

**Энэ апп → Anki.** «Anki TSV татах» нь `#separator:tab`, `#html:true`, `#tags column:3`, `#deck column:4` толгойтой, шинэ мөрийг `<br>` болгосон, таб/шинэ мөр агуулаагүй TSV үүсгэнэ. Anki дээр `Файл → Импорт`-оор оруулаад талбарыг Асуулт/Хариулт/Шошго/Багц гэж тохируулна. «CSV татах» нь хүснэгт програмд зориулсан RFC 4180 CSV (толгой мөртэй).

**`.apkg` тухай.** `.apkg` нь ZIP дотор SQLite (`collection.anki21`, орчин үеийн хувилбарт zstd-оор шахсан) агуулдаг. Энэ апп SQLite/zstd декодер ачаалахгүй тул `.apkg`-ыг шууд уншихгүй — файл сонгоход шалтгааныг тайлбарлаж, Anki-ийн текст экспорт руу чиглүүлнэ. Энэ нь санаатай хязгаарлалт: бинарыг «таамаглаж» унших нь чимээгүй буруу карт үүсгэх эрсдэлтэй.

## 2. PDF-ээс текст

Модуль: [`lib/knowledge/pdf.ts`](../lib/knowledge/pdf.ts). Карт болон quiz үүсгэгчид «PDF / текст файл сонгох» товчоор ажиллана (`.pdf`, `.txt`, `.md`).

Дэмждэг:

- шахсан (`FlateDecode`, zlib болон raw) ба шахалтгүй content stream;
- `Tj`, `TJ`, `'`, `"` текст операторууд, `Td/TD/T*/Tm/ET` мөр таслалт, `TJ`-ийн сөрөг керн → зай;
- literal string-ийн escape (`\(`, `\n`, `\101`), hex string, UTF-16BE BOM;
- `/ToUnicode` CMap (`bfchar`, `bfrange`, массив хэлбэр) — үсэг нь CID кодоор бичигдсэн кирилл PDF-д зайлшгүй;
- олон хуудас, `maxChars` (анхдагч 40,000; UI 12,000) хязгаар, `truncated` туг.

Дэмжихгүй: скан хийсэн (зурагт) PDF, object stream дотор нуугдсан фонт, LZW/ASCII85 шахалт, нарийн байрлалын (layout) сэргээлт. Ийм үед «PDF-ээс текст олдсонгүй» гэж тайлбарлаж, текст хуулах эсвэл зургийн AI замыг санал болгоно.

## 3. Зураг ба текст

- **Текст** — «ойлголт: тайлбар» мөрүүдээс төхөөрөмж дээр загвар бэлдэх (`localCardDrafts`, `localQuizDrafts`), эсвэл онлайн Бондоокоор AI-аар бэлдүүлэх.
- **Зураг** — төхөөрөмж дээр JPEG болгон дахин кодлож, зөвхөн хэрэглэгч зөвшөөрвөл AI руу илгээнэ. Төхөөрөмж дээр OCR хийхгүй.
- Хариулт бүрийг хэрэглэгч хянаж, засаж байж хадгална — AI/загварын гаргалт шууд санд орохгүй.

## 4. Шалгалт

- `tests/anki.test.ts` — 9 тест: Anki meta толгой, HTML цэвэрлэлт, RFC 4180 ишлэл, тусгаарлагч таних, алгасалт, TSV/CSV экспорт ба буцааж унших, таб/шинэ мөр үлдэхгүй байх.
- `tests/pdf.test.ts` — 6 тест: энгийн stream, Flate, ToUnicode CMap (кирилл), `TJ` керн ба escape, тэмдэгтийн хязгаар, алдааны мессеж (PDF биш, текстгүй).
- `tests/import.test.ts` — 6 тест: багц үүсгэх, давхардлыг алгасах, шошго нэгтгэх, хязгаар/алдаа, `dueOn`, экспорт → импорт round-trip.

## 5. Хязгаар

- Импорт нь зөвхөн асуулт/хариулт/шошго/багц; Anki-ийн загвар (notetype), media файл, түүх дамждаггүй.
- Давхардлыг зөвхөн сонгосон багц дотор шалгана (өөр багцад ижил асуулт зөвшөөрөгдөнө).
- PDF-ийн текстийн дараалал нь объектын дараалалд тулгуурлана; хоёр баганатай PDF-д мөр холилдож болно.
