# Таймерын дуу, тоолол ба загвар

## Хэрэглэгчид өөрчлөгдсөн зүйл

- Тохиргоо → Хугацаа ба сануулга → Таймерын дуу ба харагдац: Зөөлөн хонх, Тайван аялгуу, Гэгээлэг аялгуу гэсэн 3 сонголт. Аялгуу бүр 5 өнгөтэй, 3 давталттай, нийт ойролцоогоор 8.8 секунд. Дууны түвшинг 0–100% тохируулна.
- Турших, Дууг зогсоох товчнууд тусдаа. Туршилт нь үндсэн дууны унтраалгыг түр үл харгалздаг боловч сонгосон түвшин, чичиргээний тохиргоог дагана. Таймер ажиллаж байх үед туршилт идэвхгүй.
- Дуу хаагдсан үед туршилтын хэсэг тайлбар харуулна. Чичиргээг дуунаас тусдаа унтрааж болно; төхөөрөмжийн дэмжлэг шаардлагатай.
- Дуусах цонхны эхний том товч нь **Дууг зогсоох**. Бодит oscillator/gain холболтуудыг тасалж, ирээдүйд товлосон өнгө, хүлээгдэж буй audio resume, чичиргээ, гарчгийн анивчилтыг цуцална. Үр дүнгээ харах болон Escape мөн дохиог зогсооно.
- Цонх нь native dialog: арын хэсгийг идэвхгүй болгож, фокусыг барина. Гар утсанд хоёр товч тусдаа мөрөнд байна.
- Хугацаа 10 секунд үлдэхэд 10 → 1 гэсэн харагдах тоолол, зөөлөн богино дохио гарна. Энэ нь дуугаар тоо хэлэх биш. Тоолол болон тооллын дууг тусад нь унтраана. Тооллын дууг зогсоох нь тухайн таймерын үлдсэн тооллыг чимээгүй болгоно; таймер үргэлжилж, дуусахад үндсэн дохиогоо өгнө.
- Браузер түр зогсож сэргэсэн үед алдсан тоонуудыг дараалан дуугаргахгүй. Хоцорсон audio resume мөн хуучин тооллыг бөөнд нь тоглуулахгүй.
- Цагираг, Цахим цаг, Энгийн гэсэн 3 загвар; өрөөний жижиг таймерт мөн үйлчилнэ. Үлдсэн хугацааг дээш бүхэлчилж харуулдаг тул бодит хугацаа дуусаагүй байхад 00:00 болохгүй.

## Хадгалалт ба хамрах хүрээ

Одоогийн `settings.extras` дотор `timerChime`, `timerDesign`, `timerVibration`, `timerCountdown`, `timerCountdownSound` хадгална. Одоогийн `completionVolume`, `sound`, `notifications`, `timerWarningSeconds`-ийг ашиглана. Шинэ өгөгдлийн сан, хадгалалтын систем, dependency нэмээгүй.

Хөгжмийн мини тоглуулагч өөрийн audio context/provider-той хэвээр; таймерын Stop түүнд хүрэхгүй. Суралцсан цаг, session хадгалах алгоритм болон календарийн логикийг өөрчлөөгүй.

Суурь `5102392` дээр төсөл хөрвөхөд саад болж байсан хоёр алдааг хамгийн бага хэмжээгээр зассан: `hooks/use-study.tsx`-ийн дутуу ternary нөхцөлд `: theme` нэмсэн; `components/world/customize.tsx`-д аль хэдийн ашигласан `Icon`-ийн import нэмсэн. Эдгээрийн загвар, функцэд нэмэлт өөрчлөлт хийгээгүй.

## Утас түгжээтэй үед — бүрэн хэрэгжээгүй хэсэг

Одоогийн төсөл серверээс хугацаанд нь илгээдэг Web Push үйлчилгээ, захиалгын бүртгэл, найдвартай background scheduler-гүй. Тиймээс **утас түгжээтэй, браузерын процесс түр зогссон эсвэл апп хаалттай үед яг хугацаанд нь мэдэгдэл хүргэнэ гэж батлахгүй**. Таймер сэргэсэн үед бодит elapsed хугацаагаа тооцож дуусна, гэхдээ дохио хоцорч болно.

Одоо мэдэгдэл илгээх оролдлого audio resume-г хүлээхгүй. Дэмжигдсэн үед одоогийн service worker-аар `showNotification` ашиглана. Ард ажиллаж байхад OS-ийн ердийн мэдэгдлийн дууг зөвшөөрнө; вэб мэдэгдэл дээр сонгосон custom аялгууг системийн дуу болгохгүй.

Тохиргоонд мэдэгдэл турших товч, iPhone дээр үндсэн дэлгэцэд суулгаж зөвшөөрөл өгөх заавар болон энэ хязгаарлалтыг ил харуулсан. Энэ туршилт амжилттай байсан ч түгжээтэй үеийн товлосон дохиог батлахгүй. Яг цагтаа дуугарах шаардлагатай үед утасны үндсэн таймерыг давхар ашиглана.

Үлдсэн ажлыг бодитоор хийхэд HTTPS дээр байршуулсан апп, төхөөрөмжийн push subscription, серверийн хадгалалт/товлол, pause/resume/cancel-тай синхрончлол, илгээх үйлчилгээ болон бодит iOS/Android төхөөрөмжийн туршилт шаардлагатай. Web Push өөрөө ч сүлжээ, OS-ийн тохиргоо, Focus горимоос хамаарна.

Албан ёсны тайлбар: [WebKit — Web Push for Web Apps on iOS and iPadOS](https://webkit.org/blog/13878/web-push-for-web-apps-on-ios-and-ipados/).

Хонхны дууны сонсож харьцуулах жишээ: [Meditation Bell Sounds Effect](https://www.youtube.com/watch?v=_vgG9Oq6xHw). Хайлтаар олсон лавлагаа; энд аудиог нь сонсож хамгийн сайн гэж баталгаажуулаагүй. Энэ видеог таймерт хуулж суулгаагүй, татаж/задалж аваагүй. Бодит дохио нь апп дотор үүсдэг өөрийн 3 аялгуу бөгөөд YouTube-ийн сүлжээ, iframe, autoplay-аас хамаарахгүй.

## Шалгалт

- Таймерын **20 шинэ тест** тэнцсэн: гурван аялгууны гурван давталт, бүх scheduled note-г Stop таслах, хожуу resume цуцлах, дуугүй үед чичиргээ зогсоох, title сэргээх, 0% дуу/чичиргээ/тооллын унтраалга, audio-г хүлээхгүй мэдэгдэл, API алдаа тусгаарлах, 10 → 1 тоолол, Stop/дахин эхлэх, pause, stopwatch, warning доторх амьд тоолол, дуусах dialog, Escape/үр дүн, тохиргооны хадгалалт, 3 загварт ижил хугацаа, тооллын хязгаарууд.
- TypeScript тэнцсэн. ESLint алдаагүй; суурь хувилбарын `animated-buddy.tsx` дахь `<img>` зөвлөмж хэвээр.
- `npm run build` тэнцсэн. Эхний оролдлогод Turbopack-ийн хуучин build cache эвдэрсэн тул cache-г тусад нь шилжүүлж, цэвэр build амжилттай хийсэн.
- **`npm run check` тэнцсэн: 182 тест / 20 файл, TypeScript, ESLint, production build.** Таймерын patch-гүй `5102392` суурийг тусдаа worktree-д compilation засвартай ажиллуулахад ч унасан хоёр хуучин UI тестийг шинэ дэлгэцтэй нь тааруулсан: Sakura сонгохын өмнө “Бусад өрөө (6)” товчийг нээдэг болсон; календарийн давхардсан нэрийг зөвхөн “Биелсэн алхмууд” хэсгээс шалгадаг болсон. Хадгалалт, огноо, үр дүнгийн баталгааг хасаагүй, тест алгасаагүй. Өрөө/календарийн функцийг эдгээр тестэд тааруулан өөрчлөөгүй.
- Нэг зэрэг нийт тест ажиллуулах эхний оролдлогод AI fallback-ийн хүлээлт мөн унасан; тухайн UI файлын дахин шалгалт болон сүүлийн нийт шалгалтад тэнцсэн.
- Нийт төслийн `npm run format:check` нь суурь хувилбарт байсан 10 файлын формат дээр унаж байна: `app/globals.css`, `app/knowledge.css`, `components/calendar/study-calendar.tsx`, `components/knowledge/hub.tsx`, `components/subjects/subjects.tsx`, `components/ui/animated-buddy.tsx`, `components/world/room-scene.tsx`, `hooks/use-study.tsx`, `lib/persistence/actions.ts`, `lib/world/room-themes.ts`. Эдгээрээс `hooks/use-study.tsx`-д зөвхөн дээр дурдсан нэг мөрийн compilation засвар орсон; үлдсэн есөн файл өөрчлөгдөөгүй. Хамааралгүй файлуудыг бүхэлд нь форматлаагүй тул GitHub CI-ийн формат шат энэ зөрүүг харуулна.
- Автомат UI тестүүд jsdom орчинд; жинхэнэ утасны дуу, чичиргээ, CSS дүрслэл, түгжээтэй дэлгэцийн мэдэгдлийг төхөөрөмж дээр баталгаажуулаагүй.
