# Тогтмол v4 — шалгалтын тайлан

Огноо: 2026-09-15. Орчин: Linux, Node.js v24.19.0, Next.js 16.3.5, TypeScript 6.0.3. Энэ тайлан эх кодын локал шалгалтыг тайлбарлана.

## Тэнцсэн шалгалт

| Шалгалт                                       | Үр дүн                                            |
| --------------------------------------------- | ------------------------------------------------- |
| `npm ci`                                      | Lockfile-аас тусдаа суулгасан                     |
| TypeScript                                    | Алдаагүй                                          |
| ESLint                                        | Алдаа, анхааруулгагүй                             |
| Vitest                                        | **89 / 89** тест, **12 / 12** файл                |
| `npm run check`                               | Бүх шат тэнцсэн, production build багтсан         |
| `npm run format:check`                        | Код, баримтын формат тэнцсэн                      |
| `npm run build`                               | Нүүр, 404, manifest ба `/api/togi` үүссэн         |
| Offline manifest                              | 21 өөрчлөгдөхгүй JS/CSS asset бүртгэсэн           |
| 10,000 хичээлийн index + 365 өдрийн статистик | **27.28 ms**, нийт 600,000 секунд гэж зөв тооцсон |

Сүүлийн хэмжилт нь Node доторх тооцоолол; браузерын бүтэн дүрслэл, IndexedDB бичилт, сүлжээний хугацаа биш. Давтан ажиллуулахад хугацаа өөрчлөгдөнө. `test-results/performance.json` нь тухайн ажиллуулалтын дүнг агуулна.

## Юуг бодитоор шалгасан бэ?

- **Хугацаа:** эхэлсэн мөч, pause/resume, сэргээх, Pomodoro-ийн хэтрэлтийн хязгаар, амралт, review/save, давхар хадгалалтгүй байх, экспортын snapshot.
- **v2/v3 → v4:** ID, түүх, тэмдэглэл, нэмэлт талбар болон ажиллаж буй timer хадгалагдах; эх хадгалалтыг нөөцөлсний дараа бичих; нөөц бүтэлгүйтвэл бичихгүй байх; давтан шилжүүлэлтгүй байх.
- **Хадгалалт ба sync:** зэрэг цонхны revision, хэрэглэгчдийн тусгаарлалт, гурван хувилбарын merge, tombstone, давхар хичээлийн alias, шинэ зорилго/хөгжмийн жагсаалт, хоёр хувилбарын зөрчлийг хадгалах.
- **Өрөө ба төлөвлөгөө:** загвар/өрөөний сонголт дахин нээхэд хадгалагдах; хуваарийг хадгалахаас өмнө урьдчилж харах; зорилгын алхмаас төвлөрөх горимд timer эхлүүлэх; Escape дарахад хугацаа алдагдахгүй байх; үр дүн болон тэмдэглэлээ хадгалах.
- **Бодит ахиц:** төлөвлөгөө чагтлахад минут, XP нэмэхгүй; зөвхөн холбогдсон хичээлийн хугацаагаар зорилгын ахиц тооцох; XP өдөрт 60-аас хэтрэхгүй; гараар зассан хугацаа, өдрийн чагтыг XP-д оруулахгүй.
- **Хөгжим:** зургаан ая/чимээ тус бүр хязгаартай, бодит тоон дууны sample үүсгэх; эхлүүлэх/түр зогсоох/үргэлжлүүлэх/цэвэрлэх; апп нээхэд өөрөө асахгүй; хуудас солиход тоглуулагч хадгалагдах.
- **YouTube:** зөвшөөрөгдсөн host ба ID шалгах; буруу холбоосоор iframe ачаалахгүй; албан ёсны API-д `autoplay:0`, controls, playsinline дамжуулах; тоглуулагчийг багасгахын өмнө pause хийх. API болон аудио төхөөрөмжийг эдгээр тестэд орлуулсан.
- **Тоги:** local хариулт бодит статистик, тэмдэглэлээс гарах; онлайн хүсэлтэд тэмдэглэл оруулахгүй байх; API түлхүүргүй үед paid provider дуудахгүй; нэвтрэлт/серверийн allowlist/өдрийн хязгаар; том хүсэлтээс татгалзах; зөвхөн хариултын текст буцаах, upstream алдаа/түлхүүр задруулахгүй байх.
- **PostgreSQL:** PGlite бодит SQL engine дээр хоёр migration, есөн public хүснэгтийн RLS, хэрэглэгч хоорондын хамгаалалт, atomic RPC, CAS, rollback, foreign key, шинэ зорилго/хөгжмийн round trip, хуучин v3 upload-аас татгалзах, private AI quota-г хэрэглэгч өөрчлөх боломжгүй байх.
- **PWA:** offline asset нөөцлөлт, auth/Supabase/API болон гаднын request-ийг cache-д оруулахгүй байх, хуучин cache цэвэрлэх, шинэ хувилбар хуучин цонхыг хүчээр дахин ачаалахгүй байх.

React тестүүд **jsdom** дээр ажилласан. Хөгжмийн тест дууны өгөгдөл болон удирдлагын дарааллыг шалгасан; чанга яригчаар сонсож баталгаажуулаагүй. YouTube API-г орлуулсан тест нь жинхэнэ YouTube сүлжээ/playback-ийн баталгаа биш. AI тестүүд хиймэл түлхүүр, орлуулсан provider ашигласан; төлбөртэй хүсэлт илгээгээгүй.

## Зургийн шалгалт ба үлдсэн ажил

Өрөөний таван оригинал SVG зургийг тусад нь PNG болгож нүдээр шалгасан; ном ширээтэй давхцаж байсан байрлалыг зассан. `docs/previews` нь аппын зурган assets; бүрэн браузерын screenshot биш.

Браузерын орчин localhost/local-file хандалтыг аюулгүй байдлын дүрмээр хориглосон. Тиймээс 375/390/430/768/1024/1440 өргөн дэх бодит дүрслэл, браузерын console, YouTube playback, iOS/Android install болон төхөөрөмж дээрх offline ажиллагааг тэнцсэн гэж тайлагнаагүй. CSS, accessible label, keyboard/диалог, хөдөлгөөн багасгах тохиргоо болон тестээр шалгаж болох урсгалуудыг хийсэн.

Бодит Supabase төсөл, AI түлхүүр, Google provider, live URL тохируулаагүй. Email confirmation, Google callback, password recovery, хоёр бодит төхөөрөмжийн sync болон онлайн AI-г байршуулсан орчинд шалгах шаардлагатай. Заавар: [DEPLOYMENT.md](DEPLOYMENT.md).

GitHub-ийн тусдаа шалгалтыг [Actions](https://github.com/AriukagiinTuvshoo/TOGTMOL/actions) хэсгээс харна.
