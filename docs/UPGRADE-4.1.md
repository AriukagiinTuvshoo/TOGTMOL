# v4.1 — шаардлага ба хэрэгжилт

Суурь: `4ce55e1` (v4), 2026-09-16. Шинэ шаардлагыг хүлээж авсны дараа эхлээд одоогийн төслийг шалгасан. v4-ийн ажилладаг хэсгүүдийг үргэлжлүүлэн хөгжүүлэв.

## Эхний шалгалт

- **Хуудас:** Next App Router-ийн `/`, `/api/togi`, manifest, алдааны хуудас. Үндсэн аппын харагдацууд `components/app-shell.tsx` болон `hooks/use-study.tsx` дотор удирдагдана.
- **Өгөгдөл:** subjects, entries, sessions, tasks, studyGoals, musicSources, goals, settings, achievements, activeTimer. Баримтын хувилбар 4.
- **Хадгалалт:** IndexedDB + боломжтой үед localStorage/Web Locks; revision-оор зэрэг бичилт шалгана. Хугацааны түр тэмдэглэл тусдаа сэргээх журналтай.
- **Шилжүүлэлт:** v2/v3/v4 унших, эхийг нөөцлөх, танигдаагүй мөрийг хадгалах, давхардал/зөрчил нэгтгэх.
- **Бүртгэл:** төхөөрөмжийн болон хэрэглэгч тус бүрийн тусдаа орон зай; Supabase-ийн эзэмшигчээр тусгаарласан дүрэм, атомар синк, хоёр SQL шилжүүлэлт.
- **PWA:** хувилбар бүрийн файл нөөцлөлт, шинэчлэлтийг хуучин цонх хаагдах хүртэл хүлээлгэх, хувийн сүлжээний хүсэлтүүдийг нөөцлөхгүй байх.
- **Суурь шалгалт:** 89 тест, өмнөх GitHub Actions амжилттай. Бодит браузер/үйлчилгээний шалгалтуудын хязгаарыг өмнөх тайлангаас хадгалав.

## Өгөгдлийн шийдвэр

Өгөгдлийн хувилбар, хадгалалтын нэр, үүлэн хүснэгтүүдийг солиогүй. `extras.studyPlan`, `extras.milestoneId`, `extras.completedOn`, `world.extras.furniture` нь хуучин v4-ийн хадгалж чаддаг нэмэлт талбарууд. Шинэ төлөвлөгөөг хэрэглэгч хянаж хадгална. Өмнөх зорилго, хуваарийг нээх үед дахин үүсгэхгүй.

Үе шат, даалгаврын биелэлт нь суралцах агуулгаа эзэмшсэн гэсэн автомат дүгнэлт биш. Хэмжсэн хугацаа, гараар чагталсан алхам тусдаа үзүүлэлтүүд. Үе шат сольсны дараа өмнөх хэмжилт эхлэх үедээ холбогдсон үе шатдаа үлдэнэ.

## Баталгаажуулах хязгаар

Локал браузерын хаягт энэ орчин `ERR_BLOCKED_BY_CLIENT` өгсөн. Иймээс 320/375/390/430/768/1024/1440 дэлгэцийн бодит зураг, жинхэнэ YouTube тоглолт, iOS/Android суулгалтыг баталгаажуулсан гэж үзэхгүй. Нэвтрэлт, онлайн AI болон хоёр төхөөрөмжийн үүлэн синкийг бодит тохиргоотой орчинд шалгана. Тестийн бодит дүн: [VERIFICATION.md](VERIFICATION.md).
